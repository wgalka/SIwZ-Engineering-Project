# SZwI Engineering Project

Materiały do przedmiotu **Projekt informatyczny** dla kierunku Informatyka i ekonometria.

> Od dobrze zdefiniowanego problemu do działającego i uzasadnionego rozwiązania.

## O przedmiocie

Przedmiot jest realizowany w formie projektu zespołowego lub indywidualnego. Praca obejmuje cały cykl projektu informatycznego:

1. analizę problemu i wymagań;
2. pozyskanie oraz przygotowanie danych;
3. dobór metod analitycznych, symulacyjnych lub eksperymentalnych;
4. projektowanie aplikacji, bazy danych lub modułu analitycznego;
5. implementację i integrację rozwiązania;
6. testowanie oraz ocenę rezultatów;
7. przygotowanie dokumentacji;
8. prezentację i obronę projektu.

## Karta projektu

Na pierwszym etapie należy odpowiedzieć na pytania:

- Jaki konkretny problem rozwiązujemy?
- Kto jest odbiorcą rozwiązania?
- Jakie dane możemy realnie pozyskać?
- Co będzie minimalnym działającym rezultatem?
- Po czym poznamy, że rozwiązanie działa i jest użyteczne?
- Jakie są trzy największe ryzyka projektu?

## Kryteria oceny

- **Realizacja projektu — 50%**
- **Dokumentacja projektu — 20%**
- **Prezentacja końcowa i obrona — 20%**
- **Aktywność i postępy — 10%**

Repozytorium będzie stopniowo uzupełniane o dokumentację, dane, kod oraz rezultaty kolejnych etapów projektu.
